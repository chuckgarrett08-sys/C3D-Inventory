Dymo 4XL — Barcode batch

4×6 shipping-label print-and-cut layout. Each page fits up to 30 stickers at 1.25 × 0.50 inches, with cutting guides. Test scanner readability before making a large batch. Print at 100% / actual size and choose 4 × 6 inches paper.

These are internal Code 128 SKU barcodes, not registered retail UPCs. This standalone app creates a browser print sheet; it does not communicate directly with the printer.
